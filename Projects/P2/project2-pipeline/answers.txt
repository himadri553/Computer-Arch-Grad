## Part B  (RV32_5S_NO_FW_HZ, b_hazard.s)
B1_cycles = 12
B1_why = The first instruction needs 5 cycles to pass through all five stages, so the pipeline takes 4 extra cycles to fill, and there are no stalls because this model has no hazard detection.
B2_IF = slli x9, x8, 2
B2_ID = sub x8, x7, x5
B2_EX = add x7, x5, x6
B2_MEM = addi x6, x0, 3
B2_WB = addi x5, x0, 10
B3_alu_ctrl = ID/EX
B3_alu_op2_ctrl = ID/EX
B3_mem_do_write_ctrl = EX/MEM
B3_reg_wr_src_ctrl = MEM/WB
B3_reg_do_write_ctrl = MEM/WB
B3_rd = The register number must reach WB so the register file knows which register to write, and the write happens in WB.
B4_wrong = x7, x8, x9, x11, x12
B4_x8 = sub read x7 before add had written it, so it got the old value 0; x5 was read correctly as 10, so x8 = 0 - 10 = 0xFFFFFFF6.
B5_rule = Two instructions must sit between a producer and its consumer, because the producer writes the register in WB, the same cycle the consumer reads it in ID; with only one instruction between, the value is not written yet, and a third instruction would add a cycle for no benefit.
